# Unstaged changes: what you edited but haven't git add-ed

# Staged changes: what the next commit will contain
$ git diff --staged

Lines starting with + were added; lines starting with - were removed.

Key points

  • git log shows commits, newest first: hash, author, date, message.
  • git log --oneline is the quick-scan view.
  • git diff shows unstaged changes; git diff --staged shows staged ones.
