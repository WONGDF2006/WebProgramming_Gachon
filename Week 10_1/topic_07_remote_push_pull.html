Working with GitHub

# Once: link the local repo to an empty GitHub repo
$ git remote add origin https://github.com/USERNAME/my-project.git

# First push: -u remembers the link, so later it's just "git push"
$ git push -u origin main

# Get teammates' latest changes before you start work
$ git pull

# Download a whole repo to a new computer
$ git clone https://github.com/USERNAME/my-project.git

This course site is connected the same way:

$ git remote -v
origin  https://github.com/WONGDF2006/WebProgramming_Gachon.git (fetch)
origin  https://github.com/WONGDF2006/WebProgramming_Gachon.git (push)

Key points

  • git remote add origin URL connects your repo to GitHub (once).
  • git push uploads commits; git pull downloads and merges them.
  • git clone URL copies a repo to your computer the first time.
