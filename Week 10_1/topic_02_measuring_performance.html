Running Lighthouse

  1. Open the page in Chrome, press F12, open the Lighthouse tab.
  2. Tick Performance only, choose Mobile or Desktop, click Analyze page load.
  3. Use an Incognito window so extensions don't skew the result.
  4. Run it 2–3 times: scores vary a little between runs.

Key points

  • Aim for 90+ (green).
  • LCP and CLS have the biggest effect on how fast a page feels.
  • Real users on real phones are usually slower than the lab test.
