JPEGPhotosBaseline

WebP with a fallback, and the right size per screen

<!-- WebP first, JPEG for old browsers -->
<picture>
  <source srcset="hero.webp" type="image/webp">
  <img src="hero.jpg" alt="Campus at sunrise" width="1200" height="600">
</picture>

<!-- srcset: the browser downloads only the size it needs -->
<img src="photo-800.jpg"
     srcset="photo-400.jpg 400w, photo-800.jpg 800w, photo-1200.jpg 1200w"
     sizes="(max-width: 600px) 100vw, 800px"
     alt="Description" width="800" height="400">

Key points

  • Convert to WebP with Squoosh or TinyPNG.
  • Never ship a 4000 px photo into an 800 px slot — resize it.
  • Always set width and height so the layout doesn't shift (CLS).
