CDN — Content Delivery Network

✗ Without a CDN
User in New York → server in Seoul
~11,000 km, ~200 ms per round trip
✓ With a CDN
User in New York → edge node in New York
A few km, a few ms per round trip

Key points

  • A CDN lowers latency for users far from your server.
  • CDNs usually add compression (gzip/Brotli) and caching too.
