Git vs GitHub

Analogy: Git is like Microsoft Word, a program on your computer that tracks your document. GitHub is like Google Drive, a cloud service where you store and share it.

Git — the toolGitHub — the platform
Installed on your computerA website: github.com
Works completely offlineStores your Git history online
Saves history in a hidden .git/ folderSharing, Pull Requests, Issues, Actions, Pages
Command-line tool, created by Linus Torvalds (2005)Owned by Microsoft since 2018
Free, open sourceFree for public repos

Check your own Git version in a terminal:

$ git --version
git version 2.52.0.windows.1

Key points

  • Git is version-control software on your machine and works offline.
  • GitHub is a cloud service that hosts Git repositories.
  • You can use Git without GitHub. GitLab and Bitbucket also host Git repos.
