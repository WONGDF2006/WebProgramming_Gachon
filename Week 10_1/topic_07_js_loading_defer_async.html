JavaScript loading: defer & async

no attribute
Parsing stops → download → run → parsing resumes (slow)
async
Downloads while parsing, runs as soon as it arrives (order not guaranteed)
defer
Downloads while parsing, runs after the HTML is fully parsed, in order (best default)
HTML parsingScript downloadScript runs
<!-- ✗ Blocks parsing -->
<script src="app.js"></script>

<!-- ✓ defer: for scripts that use the DOM. Order is kept. -->
<script src="app.js" defer></script>

<!-- ✓ async: for independent scripts like analytics -->
<script src="analytics.js" async></script>

Key points

  • Use defer by default; async only for scripts that depend on nothing.
  • Both only work on external scripts (with src). For inline scripts, use DOMContentLoaded.
  • With defer, it's fine to put scripts in the <head>.
