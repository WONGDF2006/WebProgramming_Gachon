E1 · Create your first repository

$ mkdir my-first-git && cd my-first-git
$ git init -b main
Initialized empty Git repository in .../my-first-git/.git/

$ echo "<h1>Hello Git</h1>" > index.html
$ git status
On branch main

No commits yet

Untracked files:
  (use "git add <file>..." to include in what will be committed)
        index.html

$ git add index.html
$ git commit -m "Initial commit: add index.html"
[main (root-commit) 44f26b5] Initial commit: add index.html
 1 file changed, 1 insertion(+)
 create mode 100644 index.html

$ git log --oneline
44f26b5 Initial commit: add index.html

Your commit hash will be different: it's calculated from the content, author, and time.

On Windows you may see warning: LF will be replaced by CRLF. That's only Git noting Windows line endings. It's safe to ignore.
