The Git workflow — three areas

AreaWhat lives thereMove it on with
Working directoryYour files on disk, with changes Git isn't saving yetgit add
Staging areaThe changes you chose for the next commitgit commit
Local repositorySaved snapshots (commits): your historygit push
GitHubA copy of the repository in the cloudgit pull brings changes back

Moving house: the working directory is items scattered around your room; staging is boxes packed and labelled; a commit is boxes sealed and stored with an inventory; GitHub is a copy of the storage in another city.

Key points

  • Edits in the working directory aren't saved in history until you git add and git commit.
  • Staging lets you choose which changes go into the next commit.
  • Each commit is a permanent snapshot.
  • GitHub is a remote copy of your local repository.
