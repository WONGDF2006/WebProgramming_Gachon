E4 · Study Session Counter

useState holds a number; buttons change it. The count can't go below zero.

function SessionCounter() {
  const [sessions, setSessions] = useState(0);

  return (
    <section>
      <p aria-live="polite">Completed sessions: <strong>{sessions}</strong></p>
      <button type="button" onClick={() => setSessions((n) => Math.max(0, n - 1))} disabled={sessions === 0}>−1 session</button>
      <button type="button" onClick={() => setSessions((n) => n + 1)}>+1 session</button>
      <button type="button" onClick={() => setSessions(0)}>Reset</button>
    </section>
  );
}

ReactDOM.createRoot(document.getElementById('root')).render(<SessionCounter />);

Live result

setSessions((n) => n + 1) uses the previous value, which is safer than setSessions(sessions + 1) when several updates happen quickly.
