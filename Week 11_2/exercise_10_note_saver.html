E10 · Note Saver with useEffect

useEffect saves the note to localStorage whenever it changes, so it survives a page reload.

function NoteSaver() {
  const [note, setNote] = useState(() => {
    try { return localStorage.getItem('week11-note') || ''; } catch { return ''; }
  });

  useEffect(() => {
    try { localStorage.setItem('week11-note', note); } catch { /* storage blocked: nothing saved */ }
  }, [note]);   // runs after every change to note

  return (
    <section>
      <label htmlFor="note">Note</label><br />
      <textarea id="note" rows="4" cols="40" value={note} onChange={(e) => setNote(e.target.value)} />
      <br />
      <button type="button" onClick={() => setNote('')}>Clear note</button>
      <p aria-live="polite">{note ? 'Saved. Reload the page and it will still be here.' : 'No note yet.'}</p>
    </section>
  );
}

ReactDOM.createRoot(document.getElementById('root')).render(<NoteSaver />);

Live result

The function passed to useState runs only once, on the first render, so localStorage isn't read on every keystroke.
