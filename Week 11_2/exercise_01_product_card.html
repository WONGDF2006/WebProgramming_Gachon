E1 · ProductCard Challenge

A ProductCard with name, price (KRW), rating and inStock props. Bonus: show rating / 5 stars, and an Out of stock label when inStock is false.

function ProductCard({ name, price, rating, inStock }) {
  return (
    <article style={{ padding: 16, border: '1px solid #cbd5e1', borderRadius: 12, background: inStock ? '#fff' : '#f1f5f9' }}>
      <h2 style={{ margin: '0 0 6px', fontSize: '1.1rem' }}>{name}</h2>
      <p style={{ margin: '0 0 4px', fontWeight: 700 }}>₩{price.toLocaleString('ko-KR')}</p>
      <p style={{ margin: '0 0 8px' }}>{rating} / 5 stars</p>
      {inStock
        ? <span style={{ color: '#15803d', fontWeight: 600 }}>In stock</span>
        : <span style={{ color: '#b91c1c', fontWeight: 600 }}>Out of stock</span>}
    </article>
  );
}

const products = [
  { id: 'earbuds', name: 'Wireless Earbuds', price: 89000, rating: 4.5, inStock: true },
  { id: 'keyboard', name: 'Mechanical Keyboard', price: 120000, rating: 4.8, inStock: false },
  { id: 'mouse', name: 'Gaming Mouse', price: 45000, rating: 4.2, inStock: true },
];

function ProductList() {
  return (
    <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fit, minmax(180px, 1fr))', gap: 14 }}>
      {products.map((p) => <ProductCard key={p.id} {...p} />)}
    </div>
  );
}

ReactDOM.createRoot(document.getElementById('root')).render(<ProductList />);

Live result

toLocaleString('ko-KR') adds the thousands separators: 89000 becomes 89,000. {...p} passes every field of the object as a prop.
