Task 11-A · React components & props

30 points · due at the start of class, Friday of the following week.

What to build

  1. A Vite + React project: npm create vite@latest task11 -- --template react
  2. src/StudentProfileCard.jsx with exactly five props: name, studentId, major, year, gpa.
  3. Three cards in App.jsx: yours, with your real student ID, and two classmates', with their real names.
  4. Your own CSS in src/index.css: border, padding, rounded corners, a background different from the page, a hover effect.
  5. Deploy with gh-pages (set base: '/task11/' in vite.config.js), with at least 3 meaningful commits.

Before you start on this computer

Node.js and npm aren't installed system-wide on this machine, and Vite needs them. Install the LTS version from nodejs.org first, then check with node --version and npm --version. Also note that Git here names new branches master by default (see Week 10_1 E3).
