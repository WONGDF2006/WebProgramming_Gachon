E2 · Render a list of notifications

Task: render each notification with an icon chosen by its type, using .map(), a stable key, and conditional rendering.

const notifications = [
  { id: 1, type: 'success', message: 'Profile updated successfully' },
  { id: 2, type: 'warning', message: 'Password expires in 3 days' },
  { id: 3, type: 'info',    message: 'New lecture materials available' },
];

function NotificationItem({ type, message }) {
  const icon = type === 'success' ? '✅' : type === 'warning' ? '⚠️' : 'ℹ️';
  return <li><span aria-hidden="true">{icon}</span> {message}</li>;
}

function NotificationList() {
  return (
    <ul>
      {notifications.map(n => (
        <NotificationItem key={n.id} type={n.type} message={n.message} />
      ))}
    </ul>
  );
}

ReactDOM.createRoot(document.getElementById('root')).render(<NotificationList />);

Live result

The icon is marked aria-hidden so screen readers read the message without saying "check mark" first.
