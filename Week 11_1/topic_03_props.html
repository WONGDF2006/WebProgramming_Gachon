Props — passing data

Props (properties) pass data from a parent component to a child, written like HTML attributes. The child can read them but must not change them.

function App() {
  return (
    <div>
      <StudentCard name="Amir Tashkentov" year={2} />
      <StudentCard name="Gulnora Nazarova" year={3} />
    </div>
  );
}

// The child gets one object, props
function StudentCard(props) {
  return <h3>{props.name} · Year {props.year}</h3>;
}

// Destructured: the cleaner, preferred style
function StudentCard({ name, year }) {
  return <h3>{name} · Year {year}</h3>;
}

Strings vs other values: year="2" passes the string "2"; year={2} passes the number 2. Numbers, booleans and expressions go in { }.

Default values

function Button({ label = 'Click me', color = 'blue', disabled = false }) {
  return <button style={{ background: color }} disabled={disabled}>{label}</button>;
}

<Button />                             // "Click me", blue
<Button label="Submit" />              // still blue
<Button label="Delete" color="red" />  // both custom

props.children

// Whatever sits between the opening and closing tags becomes children
function Panel({ title, children }) {
  return (
    <div className="panel">
      <h2>{title}</h2>
      <div className="panel-body">{children}</div>
    </div>
  );
}

<Panel title="Week 11">
  <p>React session today</p>
</Panel>

Key points

  • Props flow from parent to child and are read-only.
  • Destructure them: function Card({ name, year }).
  • Set defaults with { label = 'OK' }.
  • children holds the JSX between a component's tags.
