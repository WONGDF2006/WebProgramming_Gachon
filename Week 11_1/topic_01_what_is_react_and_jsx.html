What is React & JSX?

React lets you describe what the UI should look like for the current data, and it updates the DOM efficiently when that data changes.

JSX lets you write HTML-like markup inside JavaScript. A build tool (Babel, Vite) turns it into React.createElement() calls.

// JSX (what you write)
const element = <h1 className="title">Hello, {name}!</h1>;

// What it compiles to (you never write this)
const element = React.createElement('h1', { className: 'title' }, 'Hello, ' + name + '!');

JSX rules that differ from HTML

HTMLJSXWhy
classclassNameclass is a JavaScript keyword
forhtmlForfor is a JavaScript keyword
<img>, <br><img />, <br />Every element must be closed
<!-- comment -->{/* comment */}HTML comments aren't valid in JSX
 
function App() {
  const user = 'Amir';
  return (
    // Return ONE root element (or a <>...</> Fragment)
    <div className="app">
      <h1>Welcome, {user}!</h1>               {/* JS expressions go in {} */}
      <p>Today: {new Date().toDateString()}</p>
      <img src="photo.jpg" alt="Profile" />   {/* self-closed */}
    </div>
  );
}

Key points

  • JSX is HTML-like syntax that compiles to React.createElement().
  • Use className and htmlFor; close every element.
  • Put JavaScript expressions inside { }.
  • A component returns one root element or a Fragment.
