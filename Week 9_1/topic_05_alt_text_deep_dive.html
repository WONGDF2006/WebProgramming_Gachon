alt text deep dive

Decision tree

Purely decorative? (border, texture, flourish) Use alt="". Screen readers skip it. Never leave the attribute out.
Inside a link? Describe where the link goes: alt="Gachon University homepage".
Informational? (photo, chart, diagram) Say what it tells you. Not alt="chart" but alt="Bar chart: enrollment rose 23% from 2024 to 2026".
An image of text? (code screenshot, receipt) Use real text instead. If you can't, put the full text in alt.

Examples

<!-- ✗ Missing alt (worst case) -->
<img src="profile.jpg">

<!-- ✗ Useless: screen reader says "image, image" -->
<img src="profile.jpg" alt="image">

<!-- ✗ Filename as alt -->
<img src="profile.jpg" alt="profile.jpg">

<!-- ✓ Informational -->
<img src="profile.jpg" alt="Kim Jisoo, Web Programming student">

<!-- ✓ Decorative -->
<img src="decorative-wave.svg" alt="">

<!-- ✓ Complex chart: short alt + long description -->
<figure>
  <img src="chart.png" alt="Enrollment bar chart — see caption below"
       aria-describedby="chart-desc">
  <figcaption id="chart-desc">
    2024: 1,200 students; 2025: 1,400; 2026: 1,476.
  </figcaption>
</figure>

Key points

  • Every <img> needs an alt attribute, even if it is empty.
  • Use <figcaption> or aria-describedby for long descriptions.
