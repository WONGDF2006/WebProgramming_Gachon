ARIA attributes

AttributePurposeExample
aria-labelA name for an element with no visible text<button aria-label="Close dialog">✕</button>
aria-describedbyPoints to extra description text<input aria-describedby="pwd-hint">
aria-hiddenHides decoration from screen readers<span aria-hidden="true">🏠</span> Home
aria-liveAnnounces content that changes<div aria-live="polite">Saved</div>
aria-expandedSays whether a section is open<button aria-expanded="false">Menu</button>
roleA role, only when no native element exists<div role="alert">Form saved!</div>

Try it: aria-expanded + aria-live

Accessibility means designing so everyone can use your site.

The first rule of ARIA: don't use ARIA. <button> beats <div role="button">; <label> beats aria-label. ARIA is for widgets with no HTML element, like custom tabs or sliders.
