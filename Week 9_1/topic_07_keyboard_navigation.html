Keyboard navigation

Tab — forward

To the next link, button, or input. Other elements need tabindex="0".

Shift+Tab — back

To the previous one. Tab order should follow reading order.

Enter / Space — activate

Enter follows links and presses buttons; Space presses buttons and checkboxes.

Arrow keys — inside widgets

Move between options in radio groups, menus, tabs, and sliders.

Focus styles and tabindex

/* ✓ Ring for keyboard focus, not for mouse clicks */
:focus-visible { outline: 3px solid #1a7f5a; outline-offset: 3px; }

/* ✗ Never — keyboard users lose track of where they are */
*:focus { outline: none; }

<!-- tabindex="0": add to the normal Tab order -->
<div role="button" tabindex="0">Custom widget</div>

<!-- tabindex="-1": focusable from JS only -->
<div id="modal" tabindex="-1">...</div>

<!-- Skip link: jump past the navigation -->
<a href="#main-content" class="skip-link">Skip to main content</a>
<nav>...</nav>
<main id="main-content">...</main>

Key points

  • Never use outline: none without another visible focus style.
  • Avoid positive tabindex values; they break the natural order.
  • A skip link (WCAG 2.4.1) lets keyboard users jump past repeated navigation.
