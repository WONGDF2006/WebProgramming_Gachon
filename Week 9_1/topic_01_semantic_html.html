Semantic HTML = structure with meaning

✗ Div soup — no landmarks

<div class="top">
  <div class="menu">...</div>
</div>
<div class="content">
  <div class="big-text">News</div>
  <div class="post">...</div>
</div>
<div class="bottom">...</div>

✓ Semantic — a screen reader can jump around

<header>
  <nav>...</nav>
</header>
<main>
  <h1>News</h1>
  <article>...</article>
</main>
<footer>...</footer>

What each landmark gives the user

  • <header> → "banner" — the site header
  • <nav> → "navigation" — jump straight to the menu
  • <main> → "main" — skip everything and start reading
  • <article> → a self-contained piece, like one post
  • <footer> → "contentinfo" — contact and copyright
  • <h1>–<h6> → a heading outline; don't skip levels
