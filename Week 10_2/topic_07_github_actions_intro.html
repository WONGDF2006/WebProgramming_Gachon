GitHub Actions

GitHub Actions is GitHub's automation system. A workflow is a YAML file in .github/workflows/ that says what to run and when.

# .github/workflows/deploy.yml — runs on every push to main
name: Deploy to Pages
on:
  push:
    branches: [ main ]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Deploy
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./
CI — Continuous Integration

Test the code automatically on every push.

CD — Continuous Deployment

Deploy automatically when the tests pass.

This course site has no workflow file. "Deploy from a branch" runs a built-in GitHub Pages workflow for you. You only write your own when the site needs a build step (React, Vue, Vite…).

Key points

  • Actions run automatically on repo events: push, pull request, schedule…
  • Workflows are YAML files in .github/workflows/.
  • Plain static sites don't need one; Pages deploys them for you.
