index.html is everything

When someone visits a folder URL like https://you.github.io/webpro-w9/, the server sends that folder's index.html. Without one, they get a 404.

webpro-w9/
├── index.html       ← required: the homepage
├── about.html
├── css/style.css
├── js/app.js
├── images/banner.jpg
└── 404.html         ← optional: custom "not found" page

A real example from this course

Until 3 Nov 2026, …/WebProgramming_Gachon/Week%209_1/ returned 404, because that folder had no index.html. Adding a Week 9_1 overview page named index.html fixed it.

Use relative paths. href="/css/style.css" points at USERNAME.github.io/css/style.css, outside your project. Write href="css/style.css" instead. (The one exception is 404.html. See exercise 3.)

Key points

  • index.html in the repo root is the homepage.
  • Every folder you link to needs its own index.html.
  • Use relative paths, not paths that start with /.
