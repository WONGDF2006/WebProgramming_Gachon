The URL structure

https://USERNAME.github.io/REPO-NAME/about.html
         username             repository  file path in the repo
TypeURLRepo name
Personal sitehttps://USERNAME.github.io/Must be exactly USERNAME.github.io
Project sitehttps://USERNAME.github.io/REPO/Any other repo

A folder with a spaceWeek 9_1/ becomes Week%209_1/ in the URL

Custom domains (like yourname.com) are free too: add a CNAME file and set up DNS.

Key points

  • Project site: https://USERNAME.github.io/REPO/ (keep the trailing slash).
  • Personal site: the repo must be named USERNAME.github.io.
  • File paths in the repo become paths in the URL. Spaces become %20.
