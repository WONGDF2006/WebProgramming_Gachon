What is deployment?

Right now a site on your computer can only be seen by you. Deployment copies it to a server so anyone with the URL can open it. A static site is just HTML, CSS, and JavaScript files, with no code running on the server.

🆓 GitHub Pages

Free static hosting. Deploys with git push.

⚡ Netlify / Vercel

Free tier, fast, auto-deploy, supports build steps.

🖥️ VPS / Cloud

AWS, GCP, Azure: full control, you manage the server, costs money.

🐳 Docker

Package an app to run anywhere. Industry standard.

Key points

  • Deployment puts your site on a server with a public URL.
  • Static sites (HTML/CSS/JS) need no server-side code.
  • GitHub Pages is the simplest free option for static sites.
  • Apps with Node.js, PHP, or databases need a different host.
