E3 · Create a custom 404 page

This course site now has one: try a page that doesn't exist.

# 1. Create 404.html in the repo root
# 2. Commit and push
$ git add 404.html
$ git commit -m "Add custom 404 page"
$ git push
# 3. Wait about a minute, then visit a missing URL again

The one place to use an absolute path

GitHub serves 404.html for any missing address, including ones deep in folders like …/Week%209_1/missing.html. A relative link such as href="index.html" would then point at Week 9_1/index.html, not the course home. So this site's 404 page links home with the full project path:

<a href="/WebProgramming_Gachon/">Back to the Course Library</a>

For the same reason, the page keeps its CSS inside a <style> tag instead of linking a stylesheet by a relative path.
