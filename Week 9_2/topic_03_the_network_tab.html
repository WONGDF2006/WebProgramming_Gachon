The Network tab

Queueing
Waiting for a free connection
DNS lookup
Domain name → IP address
Connect + SSL
TCP handshake + TLS
TTFB
Server thinking until the first byte
Download
Transferring the file

Long TTFB (over ~600 ms) means a slow server. Long download means the file is too big.

Tips

  • Throttle to "Slow 4G" or "3G" to feel what mobile users feel.
  • Sort by Size to find the heaviest files first.
  • Filter by Img, JS, or CSS.
  • Tick Disable cache to test a first-time visit.
  • Look for red rows (4xx/5xx): failed requests waste time.
