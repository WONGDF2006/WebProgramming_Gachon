Color contrast

4.5 : 1Normal text — WCAG AA
3 : 1Large text (18pt+, or 14pt+ bold) — WCAG AA
7 : 1Normal text — WCAG AAA

Fail vs pass on white

#ff9999 — fail (2.1 : 1) #ff9900 — fail (2.1 : 1) #767676 — pass AA (4.5 : 1) #595959 — pass AAA (7 : 1) White on #1a7f5a — pass AA (5 : 1)

Tools for checking contrast

  • WebAIM Contrast Checker — webaim.org/resources/contrastchecker
  • Chrome DevTools — inspect text and click the colour swatch to see the ratio.
  • Lighthouse — flags every element with low contrast.
  • Colour Contrast Analyser — a desktop eyedropper for anything on screen.

Key points

  • Decorative graphics and disabled controls are exempt.
  • Light grey on white is the most common failure.
