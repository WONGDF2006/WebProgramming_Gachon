Caching

Cache-Control headers (set by the server)

Cache-Control: public, max-age=31536000, immutable   ← 1 year: versioned CSS/JS, fonts
Cache-Control: public, max-age=3600                  ← 1 hour: content that changes sometimes
Cache-Control: no-cache                              ← always check with the server first (HTML)
Cache-Control: no-store                              ← never store (private data)

304 Not Modified

  1. First visit: the server sends the file plus an ETag (a fingerprint) or Last-Modified date.
  2. When the cached copy expires, the browser asks: "has it changed?" (If-None-Match).
  3. If not, the server answers 304 Not Modified with no body. The browser reuses its copy.

In DevTools → Network, a reused file shows (memory cache), (disk cache), or a 304 status.

Cache busting

<link rel="stylesheet" href="styles.a3f9c2b1.css">
<script src="app.d8e4f2a9.js" defer></script>

Change the file → the hash changes → new URL → the browser downloads the new version. Build tools add the hash for you.
